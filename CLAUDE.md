# BPP brand awareness dashboard: project context

Own project (private repo `clclyde/bpp-awareness-dashboard`, separate from the PediaWell dashboard). Streamlit 1.66.0 prototype for BPP (Budol-Proof Pinoy: Facebook page and TikTok), requested by Sir Joven.

- Design (editorial, redone 2026-10-20): the page opens with the finding as a headline sentence, then big figures with sparklines (native `st.metric`, no card boxes), then evidence. Colours are the Project Swarm deck palette (white, navy #073763, blue #0B3691, yellow #F1C232, red #D10000, text #3F3F3F); fonts Montserrat (body) and Source Serif 4 (headings), all set in `.streamlit/config.toml`. The only custom HTML is a plain yellow rule at the top and a red bar at the bottom. Tabs: First vs second half (default view, requested by Sir Joven 2026-10-20: two equal periods side by side with growth and cost, own selector of period length and start month, default 6 months per period, first period starting Oct 2025: Oct 2025 to Mar 2026 vs Apr to Sep 2026 (chosen 2026-10-21; the start month stays selectable); TikTok is only compared when its data covers the first period; no video view-through here, the exports have no ThruPlays before Mar 2026), Overview, Awareness trend, Content. Follows Streamlit's own design guidance: theme in config.toml, native metrics/dataframes, no CSS unless asked. Needs Streamlit 1.66 (bordered/sparkline metrics, `delta_description`, theme fonts and chart palettes).
- Data: Supabase `pulse.social_ads_monthly`, `fb_posts`, `tiktok_videos` and BPP rows of `ad_spend_monthly`, read with the read-only `pulse_reader_bpp` login (secrets or `PULSE_DB_*` env vars). Local fallback: git-ignored `data/bpp_snapshot.json`. Source of the data: BPP Content SSOT sheet (Ads Manager exports, Facebook post tabs + YTD Meta, YTD TikTok + the 2025 TT tabs). Refresh is manual: rebuild the snapshot, run `supabase/loaders/gen_22_bpp_seed.py` (parent project, git-ignored), run the seed in Supabase.
- Definitions follow the deck: reach is the sum of campaign reach rows (overstates unique reach), monthly not weekly, no target audience yet (card pending); frequency = impressions / reach; cost per 1,000 reached = spend / reach x 1,000 (reach campaigns only in comparisons); engagement rate = (reactions + comments + shares) / reach; TikTok has views only. Aug and Sep 2025 figures in the SSOT "Tables" tab are 2025, not targets.
- TikTok has no videos in the SSOT for Oct to Dec 2025: treated as missing data, not zero: the comparison tab shows the partial total labelled "(partial)" with the months it covers, and no change percentage, until the owner confirms or supplies the data. The explanatory notes about the missing months (comparison tab and Overview) are internal-view only; the client sees just the "(partial)" label and the months it covers.
- Known data gaps: Feb, Apr and May 2026 Ads Manager exports are incomplete (spend below the Ad Spend Report; shown yellow on the trend charts); March 2026 is exported per ad; the JUL - Meta tab header is broken (handled).
- Rules: never commit `data/` or `secrets.toml`; only the read-only BPP login in the app; never ask for or print passwords; run with a venv built from requirements.txt (Streamlit 1.66; the shared ../.venv still has 1.38 for PediaWell) or Python 3.12; verify changes by running the app and checking September 2026 (spend 19,458.54, reach 1,014,541, cost per 1,000 reached 19.18).
- Client vs internal view: the sidebar has an "Internal view" switch (off by default). Off = what the client sees (no source line, no yellow markers, no Ads Manager vs Ad Spend Report data check). On = the team's data-quality view. It is a display switch, not security. Real fix: re-export Feb, Apr and May 2026 in the SSOT.
- Deck: `report_deck.py` builds the 8-slide Swarm-look .pptx (see README_REPORT.md); `out/` is git-ignored. Needs `requirements-report.txt` (python-pptx). Google Slides template fill is not built (no template yet).
- Access password: optional `app_password` in Secrets (top level, above `[supabase]`) or APP_PASSWORD env var; when set the app shows a password form and loads nothing until it matches (`hmac.compare_digest`). Unset = open. Shared secret, no lockout, not real security.
- Open items: target audiences and weekly reach (not in the SSOT), sentiment tab, follower growth, brand health, an n8n loader to refresh the Supabase tables.
